LocalFlow — unsigned pilot, macOS 14+, US English

1. Extract this ZIP. Run: bash ./install.sh
2. Open ~/Applications/LocalFlow.app in Finder. Approve through macOS.
3. Select Whisper Tiny English. Click Download Whisper Tiny (32 MB), or import
   ggml-tiny.en-q5_1.bin if offline. Alternatively run: bash ./download-model.sh
4. Allow Microphone, Accessibility, and Input Monitoring in Setup. Apple Speech
   permission/assets are needed only if you choose the Apple engine.
5. Focus a text field. Hold Control–Option–Space, speak, release all keys.

Escape cancels. Never submits. No clipboard use. Ten minutes maximum.
The destination app can store or transmit the inserted text.

The installer is offline and requires no compiler, package manager, or sudo.
It does not strip quarantine or disable Gatekeeper. Unsigned updates can
require fresh macOS permission grants. Quit LocalFlow before an update.

Rollback: bash ./install.sh --rollback
Uninstall: bash ./uninstall.sh
Previous apps remain in ~/Applications/LocalFlow Backups.

Source, privacy boundary, and validation: github.com/vitoriomexas311/local-wispr-flow
No company-wide CUI compliance certification is implied.

Whisper model provisioning is the only optional network download. Dictation
never sends audio/text out. For company offline setup, transfer the model file
and run: bash ./download-model.sh /path/to/ggml-tiny.en-q5_1.bin
The SHA-256 is checked before installation. The model stays in
~/Library/Application Support/LocalFlow/Models across app upgrades/uninstall.
Remove that directory yourself if you also want to remove the downloaded model.
With the lid closed, use an external microphone: macOS disconnects the built-in mic.
