LocalFlow — macOS 14+, unsigned pilot

1. Extract the universal offline ZIP.
2. Run: bash ./setup.sh
3. Approve LocalFlow in macOS and allow Microphone, Accessibility, Input Monitoring.
4. Focus a text field. Hold the shortcut shown in LocalFlow, speak, and release.

Change the shortcut in LocalFlow. Escape cancels. Ten minutes maximum.
The universal offline ZIP includes Whisper Tiny English (32 MB) for Apple Silicon
and Intel. Setup needs no network, compiler, package manager, account, or sudo.
An app-only ZIP downloads the model once instead. Force offline import with:
  bash ./setup.sh --offline /path/to/ggml-tiny.en-q5_1.bin

Keep the lid open or select an external microphone in System Settings → Sound.

Quit LocalFlow before updating. The installer preserves the previous app.
Rollback: bash ./install.sh --rollback
Uninstall: bash ./uninstall.sh
The model remains in ~/Library/Application Support/LocalFlow/Models.

Unsigned/unnotarized: macOS may require Privacy & Security → Open Anyway.
Setup never disables Gatekeeper or strips quarantine. Updates can require fresh
permission grants. No public release is validated until its exact-artifact
microphone, cross-app and whole-device offline acceptance is recorded.

LocalFlow does not save audio/transcripts, use the clipboard, or send dictations
out. Destination apps can store or transmit inserted text. No CUI certification.
